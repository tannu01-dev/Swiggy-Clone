# 🍔 Swiggy Clone — Full-Stack Food Delivery Platform

A **full-stack food delivery web application** inspired by Swiggy, built to demonstrate real-world frontend, backend, database, API integration, and deployment skills.

### 🔗 Live Demo

**Frontend:** https://swiggy-clone-jfn5-git-main-tanu-b86c.vercel.app/
**Backend API:** https://swiggy-backend-1-5em7.onrender.com


## 🚀 Features

* 🍽️ Restaurant listing & restaurant details
* 📋 Dynamic menu fetching
* 🛒 Add/remove/update cart items
* 💰 Dynamic cart total calculation
* 🔄 Frontend–backend REST API integration
* 📱 Responsive UI
* 🌐 Production deployment
* 💳Payment Integration(RazorPay)

## 🛠️ Tech Stack

**Frontend:** React.js, JavaScript, HTML, CSS, React Router
**Backend:** Node.js, Express.js, REST APIs
**Database:** MongoDB, Mongoose
**Tools:** Git, GitHub, Postman
**Deployment:** Vercel, Render

## 🏗️ Architecture

```text
React (Vercel)
      ↓
REST API
      ↓
Node.js + Express (Render)
      ↓
MongoDB
```

## 📌 Key Learning

Implemented **component-based React architecture, REST APIs, MongoDB integration, asynchronous data fetching, cart state management, CORS, environment variables, and production deployment.**
