# Swiggy Clone - React.js

A Swiggy-inspired food ordering web application built using React.js.  
This project demonstrates restaurant listing, menu browsing, cart management, and dynamic routing.

## 🚀 Features

- Restaurant listing page
- Restaurant details page
- Menu items display
- Add to Cart functionality
- Cart quantity management
- Checkout page
- Dynamic routing using React Router
- Responsive UI

## 🛠️ Tech Stack
- Payment integration
- React.js
- JavaScript (ES6+)
- React Router
- HTML5
- CSS3
- Git & GitHub
